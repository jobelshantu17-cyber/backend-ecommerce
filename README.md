# 🛒 E-Commerce Backend (Node.js & MongoDB)

This repository contains the backend for an e-commerce application, built with Node.js, Express, and MongoDB.  
The focus is on API design, authentication, and database structure.

---

## 🚀 Features
- User authentication (JWT)
- Product & order APIs
- Role-based access (Admin/User)
- MongoDB schema design

---

## 🛠 Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT

---

## 📂 Folder Structure
- routes/
- controllers/
- models/
- middlewares/
